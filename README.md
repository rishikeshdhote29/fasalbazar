# 🌾 FasalBazar

FasalBazar is a full-stack agricultural e-commerce marketplace that connects farmers/sellers with buyers.

## 🚀 Features

### Buyer
- User registration and login
- Browse products
- Search products
- Add products to cart
- Place orders
- Track orders
- Manage profile

### Seller
- Seller registration and login
- Add products
- Update products
- Delete products
- Manage orders
- Manage profile

### Authentication
- JWT-based authentication
- Role-based access control
- Password reset
- Secure password hashing

### Other Features
- Cloudinary image uploads
- Stripe payment integration
- REST APIs
- MongoDB database

## 🛠️ Tech Stack

**Frontend**
- React.js
- Redux Toolkit
- Tailwind CSS
- Bootstrap

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB
- Mongoose

**Services**
- Cloudinary
- Stripe
